
# COS201-Programming-I

COS 201 Computer Programming I Practicals

## Week 3: Variables, Data Types, Expressions and Input/Output

### Programs Submitted
1. SimpleCalculator.java
2. AverageCalculator.java
3. ItemCost.java

## How to Compile and Run

Make sure Java JDK is installed on your computer.

Open a terminal in the repository folder.

### SimpleCalculator
javac week03/SimpleCalculator.java
java -cp week03 SimpleCalculator

### AverageCalculator
javac week03/AverageCalculator.java
java -cp week03 AverageCalculator

### ItemCost
javac week03/ItemCost.java
java -cp week03 ItemCost
